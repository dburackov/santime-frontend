# Спецификация: хедер, навигация и главная страница

Дополняет `DESIGN.md` (токены стиля). Этот файл — отдельный референс специально по компоновке хедера и главной страницы, чтобы отдавать его Claude Code точечно при вёрстке этих экранов.

---

## 1. Хедер — двухъярусная структура

Одновременно нужно разместить: логотип, навигацию (4 пункта), поиск, переключатель темы, корзину и два номера телефона. В одну строку — особенно на мобильном — всё это не помещается без потери читаемости. Решение — разделить на **служебную полосу** и **основной хедер**.

### Служебная полоса (только десктоп/планшет, ≥ 1024px)

Тонкая строка над основным хедером.

- **Слева** — оба телефона, каждый как кликабельная ссылка `tel:+375...`, разделены точкой.
- **Справа** — переключатель темы (солнце/луна).
- Фон — `--color-bg`, нижняя граница `--border`, без тени.
- На мобильном и планшете **не рендерится вообще** — оба элемента (телефоны, тема) переезжают в мобильное меню (см. ниже), а не просто скрываются через `display: none` с потерей доступа — доступ к ним должен сохраняться, просто в другом месте интерфейса.

### Основной хедер (sticky, все брейкпоинты)

**Десктоп (≥ 1024px):** в одну строку — логотип слева, навигация из 4 пунктов сразу после логотипа, поле поиска (растягивается на всё доступное пространство между навигацией и корзиной), иконка корзины с счётчиком количества товаров справа.

**Мобильный (< 640px):** компактный ряд из иконок — бургер-меню слева, логотип по центру (или сразу после бургера), иконка поиска и иконка корзины справа. Полноразмерное поле поиска не показывается всегда — по тапу на иконку разворачивается в полноширинную строку поверх хедера (не отдельная страница).

**Тач-таргеты на мобильном** — не менее 44×44px на каждую иконку (бургер, поиск, корзина), согласно правилу из `DESIGN.md`.

### Мобильное меню (слайд-панель по бургеру)

Открывается сбоку (drawer), содержит, сверху вниз:
1. 4 пункта навигации (Главная, Каталог, Доставка, Оплата)
2. Оба телефона (кликабельные `tel:` ссылки)
3. Переключатель темы
4. (опционально) ссылки на соцсети / реквизиты

Таким образом бургер-меню на мобильном берёт на себя роль всей служебной полосы, а не только навигации — ничего из десктопного набора функций не теряется, просто меняется точка доступа.

---

## 2. Навигация

Навигация — **всего 4 плоских пункта**: Главная, Каталог, Доставка, Оплата. Мега-меню или выпадающие списки не нужны.

**Важно:** категории товаров (Ванны, Смесители, Унитазы, Раковины и т.д.) **не дублируются** отдельными пунктами верхнего меню — они находятся внутри страницы «Каталог» как боковая навигация/фильтр. Единственное исключение — плитки категорий на главной странице (см. ниже), которые ведут на тот же каталог с применённым фильтром категории. Источник списка категорий один — таблица `category` из БД, категории не хардкодятся ни в хедере, ни на главной.

---

## 3. Обработка телефонных номеров — сводка решения

| Экран | Где отображаются телефоны |
|---|---|
| Десктоп/планшет | Оба сразу видны в служебной полосе, кликабельны (`tel:`) |
| Мобильный | Не видны в самом хедере — доступны через иконку телефона (тап открывает мини-попап с двумя номерами) **или** внутри бургер-меню (см. вариант в реализации ниже — выбрать один способ, не оба одновременно, чтобы не дублировать точку входа) |

Рекомендация: для простоты реализации — один способ доступа на мобильном (бургер-меню), без дополнительной иконки-попапа, чтобы не плодить лишний UI-элемент в и без того тесном мобильном хедере.

## 4. Главная страница — структура контента

Каталог уже отвечает за просмотр/фильтрацию — главная страница не должна его дублировать. Её задача — направить пользователя и внушить доверие (базовая цель проекта). Порядок секций сверху вниз:

1. **Hero** — конкретное УТП (например: «Сантехника с гарантией и доставкой по [регион]»), крупная кнопка-CTA на страницу «Каталог».
2. **Плитки категорий** — 4 категории (Ванны / Смесители / Унитазы / Раковины) в ряд на десктопе, 2×2 на мобильном. Единственное место на главной, где категории продублированы визуально — здесь у пользователя ещё нет доступа к фильтрам, нужен быстрый вход.
3. **Хиты продаж** — сетка карточек товара. Переиспользуется тот же компонент карточки, что и в каталоге (см. `DESIGN.md`, раздел «Карточка товара») — не создаётся отдельный вариант карточки для главной.
4. **Полоса доверия** — 4 иконки с короткой подписью: доставка / гарантия / оплата / поддержка. Иконки «доставка» и «оплата» ведут на соответствующие страницы сайта. Это ключевой блок именно под цель «выглядит надёжно, как крутой магазин».
5. **Новинки** — опционально, второй ряд карточек, если ассортимент это оправдывает на момент запуска.
6. **Отзывы/рейтинг** — для сантехники (крупная, редкая покупка) это существенно повышает доверие; блок с отзывами покупателей и рейтингом.
7. **Footer** — контакты, оба телефона повторно, ссылки на «Доставка»/«Оплата», соцсети, копирайт.
